# SPP TPA Nurut Taqwa
Web app PWA. Data tersimpan di HP (localStorage), TIDAK sinkron antarperangkat. Backup rutin lewat Pengaturan > Unduh Backup.

## Deploy gratis dari HP (Cloudflare Pages / Netlify Drop / GitHub Pages)
1. Ekstrak ZIP, unggah semua file ke GitHub (repo baru, mode "Add file > Upload files").
2. Repo > Settings > Pages > Branch: main > Save. Tunggu 1–2 menit, buka alamat https://NAMA.github.io/NAMA-REPO/
3. Buka di Chrome Android > menu ⋮ > "Tambahkan ke layar utama".
## Pemakaian
Santri > + Tambah. Bayar > + Catat Pembayaran. Laporan > Unduh CSV. Pengaturan > PIN, tarif, backup/restore.
